\section{Differential Entropy of Low-Dimensional Distributions}\label{sec:low_dim_entropy}

In this short appendix we provide a proof of the following fact.

\begin{theorem}\label{thm:degenerate_entropy_negative_infinity}
    Let \(S\) be a closed subset of \(\R^{D}\) with \(0\) volume.\footnote{Formally this means that \(S\) is Borel measurable with Borel measure \(0\).} Let \(\vx\) be a random variable with support equal to \(S\). Then \(h(\vx) = -\infty\).
\end{theorem}
\begin{proof}
    We will show this for the case \(S\) is compact and \(\vx\) is uniform on \(S\); this setting captures the essential ideas without being too technical. The basic idea is to take an \(\eps\)-thickening of \(S\), say \(S_{\eps}\) defined as 
    \begin{equation}
        S_{\eps} = \bigcup_{\vxi \in S}B_{\eps}(\vxi)
    \end{equation}
    where \(B_{\eps}(\vxi)\) is the (\(\ell^{2}\)-norm) ball of radius \(\eps\) centered at \(\vxi\), depicted in \Cref{fig:entropy_eps_thickening}.
    \begin{figure}[th]
        \centering
        \begin{tikzpicture}
            \def\radius{0.2cm} % Define epsilon value
            \def\curve{(0,0) .. controls (1,1.5) and (3,-0.5) .. (4,1)} % Define the curve S

            % Draw many overlapping circles along the curve to represent the thickening S_eps
            % Use a decoration to place marks (circles) along the path
            \path[decoration={markings, mark=between positions 0 and 1 step 0.02 with {
                    % Fill a circle at each mark; low opacity to show overlap
                    \fill[red!30, opacity=0.5, draw=none] (0,0) circle (\radius);
                }}, postaction={decorate}] \curve;

            % Draw the original curve S on top, thicker and in blue
            \draw[blue, thick] \curve node[right, blue] {$S$};

            % Choose an example point x on the curve S
            \coordinate (p_on_curve) at (2, 0.5); % Approximate point on the curve
            % Draw the specific ball B_eps(x) for this x, slightly darker/more opaque
            \fill[red!50, opacity=0.7] (p_on_curve) circle (\radius);
            % Mark the point x
            \fill[black] (p_on_curve) circle (1pt) node[below left] {$x$};
            % Add an arrow indicating the radius epsilon for this specific ball

            % Label the thickened region S_eps, placing the label appropriately
             \node[red, below right] at (3.5, -0.2) {$S_{\eps} = \bigcup_{\vxi \in S} B_{\eps}(\vxi)$};

        \end{tikzpicture}
        \caption{Illustration of the \(\eps\)-thickening \(S_\eps\) of a curve \(S \subseteq \R^{2}\).}
        \label{fig:entropy_eps_thickening}
    \end{figure}
    We will work with random variables whose support is \(S_{\eps}\), which is fully-dimensional, and take the limit as \(\eps \to 0\).

    Thus let \(\vx \sim \dUnif(S)\) such that it does not have a density\footnote{w.r.t.~the Borel measure on \(\R^{D}\).} and \(\vx_{\eps} \sim \dUnif(S_{\eps})\). Since \(S_{\eps}\) has positive volume, \(\vx_{\eps}\) has a density \(p_{\eps}\) equal to
    \begin{equation}
        p_{\eps}(\vxi) = \indvar(\vxi \in S_{\eps}) \cdot \frac{1}{\mathrm{Vol}(S_{\eps})}.
    \end{equation}
    Since \(\vx\) does not have a density, the way to make sense of \(h(\vx)\) is through the equality 
    \begin{equation}
        h(\vx) = \lim_{\eps \searrow 0}h(\vx_{\eps});
    \end{equation}
    we will show that the latter limit evaluates to \(-\infty\).

    Indeed, using the convention that \(0 \log 0 = 0\), it holds
    \begin{align}
        h(\vx_{\eps}) 
        &= -\int_{\R^{D}}p_{\eps}(x)\log p_{\eps}(x)\odif{x} \\ 
        &= -\int_{S_{\eps}}\frac{1}{\operatorname{Vol}(S_{\eps})} \log\rp{\frac{1}{\operatorname{Vol}(S_{\eps})}}\odif{\vxi} \\ 
        &= \frac{\log(\operatorname{Vol}(S_{\eps}))}{\operatorname{Vol}(S_{\eps})}\int_{S_{\eps}}\odif{\vxi} \\ 
        &= \log(\operatorname{Vol}(S_{\eps})).
    \end{align}
    Since \(S\) is compact \(\operatorname{Vol}(S_{\eps})\) is finite and tends to \(0\) as \(\eps \searrow 0\).\footnote{In the case where \(S\) is not compact and \(\vx\) is not uniform on \(S\), we define a more refined version of \(\vx_{\eps}\) whose density at \(\vxi\) changes at different rates in the directions orthogonal to and aligned with \(S\) at \(\vxi\). This density results in a different calculation which does not involve the volume of \(S_{\eps}\) but rather something like the effective volume taken up by \(\vx_{\eps}\), which is finite and vanishing as \(\eps \searrow 0\).} Thus
    \begin{equation}
        h(\vx) = \lim_{\eps \searrow 0}h(\vx_{\eps}) = \lim_{\eps \searrow 0}\log(\operatorname{Vol}(S_{\eps})) = -\infty,
    \end{equation}
    as desired.
\end{proof}

\section{Diffusion and Denoising Processes}\label{sec:entropy_diffusion}

In the main body (\Cref{ch:general-distribution}), we considered a possibly low-dimensional random variable \(\vx\), and a stochastic process defined by \eqref{eq:additive_gaussian_noise_model}, i.e.,
\begin{equation}
    \vx_{t} = \vx + t\vg
\end{equation}
where \(\vg \sim \dNorm(\vzero, \vI)\) independently of \(\vx\). Since the random variable \(\vx_{t}\) is supported on all of \(\R^{D}\), it has a \textit{density}, which we denote \(p_{t}\) (as in the main body). This density is smooth (i.e., infinitely differentiable).\footnote{Proof is left as an exercise for readers well-versed in mathematical analysis.}

Before we start, we introduce a key notation: let \(\phi_{t}\) be the density of \(\dNorm(\vzero, t^{2}\vI)\), i.e.,
\begin{equation}
    \phi_{t}(\vx) := \frac{1}{(2\pi)^{D/2}t^{D}}\exp\rp{-\frac{\norm{\vx}_{2}^{2}}{t^{2}}}.
\end{equation}

\subsection{Technical Assumptions and Implications}

\underline{\textit{This section can be skipped on a first read-through.}}

In order to perform a rigorous but not unduly difficult technical analysis, we will need to make some assumptions on the random variable \(\vx\), mostly regarding its distribution's smoothness. Most of the results we present will hold in (far) more generality than the following assumptions, but require commensurately higher-level mathematics to prove. As a result, we focus on the simplest possible case (where we can swap the order of integration, differentiate under the integral sign, etc.), captured by these assumptions.

\begin{assumption}\label{assumption:app_entropy_denoising_diffusion}
    \(\vx\) has a density \(p\) which has the following properties:
    \begin{itemize}
        \item \(p(\vxi) > 0\) for all \(\vxi \in \R^{D}\);
        \item \(p\) is twice-differentiable with a continuous second-derivative;
        \item \(\sup_{\vxi \in \R^{D}}\norm{\nabla p(\vxi)}_{2} < \infty\).
        \item \(\sup_{\vxi \in \R^{D}}\abs{\Delta p(\vxi)} < \infty\).
    \end{itemize}
\end{assumption}
Here \(\Delta\) is the Laplacian, i.e., for a function \(f \colon \R \times \R^{D} \to \R^{D}\) it is defined as
\begin{equation}
    \Delta f(t, \vxi) = \sum_{i = 1}^{D}\pdv[order=2]{f}{\xi_{i}}(t, \vxi) = \tr(\nabla^{2}f(t, \vxi)).
\end{equation}

From \Cref{assumption:app_entropy_denoising_diffusion} we can obtain uniform regularity on \(p_{t}\), namely:
\begin{lemma}\label{lem:app_entropy_denoising_uniform_regularity}
    Let \Cref{assumption:app_entropy_denoising_diffusion} prevail. We have:
    \begin{itemize}
        \item \(\sup_{t \in [0, T], \vxi \in \R^{D}}\norm{\nabla p_{t}(\vxi)}_{2} < \infty\).
        \item \(\sup_{t \in [0, T], \vxi \in \R^{D}}\abs{\Delta p_{t}(\vxi)} < \infty\).
        \item \(\sup_{t \in [0, T], \vxi \in \R^{D}}\norm{\nabla \log p_{t}(\vxi)}_{2} < \infty\).
        \item \(\sup_{t \in [0, T], \vxi \in \R^{D}}\abs{\Delta \log p_{t}(\vxi)} < \infty\).
    \end{itemize}
\end{lemma}
\begin{proof}
    The smoothed density satisfies:
    \begin{equation}
        p_{t}(\vxi) = \int_{\R^{D}}\phi_{t}(\vpsi)p(\vxi - \vpsi)\odif{\vpsi}.
    \end{equation}
    By our assumption, we can differentiate under the integral sign and obtain 
    \begin{align}
        \nabla p_{t}(\vxi) 
        &= \int_{\R^{D}}\phi_{t}(\vpsi)\nabla p(\vxi - \vpsi)\odif{\vpsi} \\
        \Delta p_{t}(\vxi)
        &= \int_{\R^{D}}\phi_{t}(\vpsi)\Delta p(\vxi - \vpsi)\odif{\vpsi}.
    \end{align}
    The triangle inequality and our hypothesis on (\(L^{\infty}\)) boundedness of \(\nabla p\) and \(\Delta p\) yield
    \begin{align}
        \norm{\nabla p_{t}(\vxi)}_{2}
        &\leq \int_{\R^{D}}\phi_{t}(\vpsi)\norm{\nabla p(\vxi - \vpsi)}_{2}\odif{\vpsi} \leq \sup_{\vpsi \in \R^{D}}\norm{\nabla p(\vpsi)}_{2} < \infty, \\
        \abs{\Delta p_{t}(\vxi)}_{2}
        &\leq \int_{\R^{D}}\phi_{t}(\vpsi)\abs{\Delta p(\vxi - \vpsi)}\odif{\vpsi} \leq \sup_{\vpsi \in \R^{D}}\abs{\Delta p(\vpsi)} < \infty,
    \end{align}
    uniformly in \((t, \vxi)\). This shows the first two claims.

    For the second two claims, it is easy to calculate via the chain rule that 
    \begin{align}
        &\nabla \log p_{t} = (1/p_{t})\nabla p_{t} \\
        &\Delta \log p_{t} = (1/p_{t})\Delta p_{t} - \norm{(1 / p_{t})\nabla p_{t}}_{2}^{2},
    \end{align}
    whenever all constituent functions are defined. We will show that these constituent functions are defined for all \(t > 0\) by Gaussian smoothing, which together with our hypotheses about \(p\) (covering the case of \(t = 0\)) will imply the claim.  Therefore 
    \begin{align}
        \norm{\nabla \log p_{t}(\vxi)}_{2}
        &=
    \end{align}
\end{proof}

\begin{remark}
    The technical assumptions in \Cref{assumption:app_entropy_denoising_diffusion} may seem onerous, but there is an easy fix to transform \textit{any} random variable \(\vx\) into one which satisfies these properties: add a small amount of independent Gaussian noise. Indeed, let \(\vg^{\prime} \sim \dNorm(\vzero, \vI)\) be independent of \(\vx\) and \(\vg\), let \(\eps > 0\), and define 
    \begin{equation}
        \vx^{+} = \vx + \eps \vg^{\prime}.
    \end{equation}
    Indeed, the random variable \(\vx^{+}\) then has the same marginal distribution as \(\vx_{\eps}\). This means that its density is positive everywhere and smooth (as intimated by the discussion at the beginning of \Cref{sec:entropy_diffusion}), and we have the appropriate control on \(\nabla p^{+}\) and \(\Delta p^{+}\) (as given to us by \Cref{lem:app_entropy_denoising_uniform_regularity}).

    In practice, most low-dimensional distributions are not \textit{exactly} low-dimensional: they are concentrated near a low-dimensional set, but still have some noise. So we expect that \Cref{assumption:app_entropy_denoising_diffusion} more or less applies to real random variables.
\end{remark}

\subsection{Diffusion Process Increases Entropy Over Time}\label{sub:diffusion_entropy_increases}

In this section appendix we provide a proof of \Cref{thm:diffusion_entropy_increases}. For convenience, we restate it as follows. 

\begin{theorem}[Diffusion Increases Entropy]\label{thm:diffusion_entropy_increases}
    Let the notation at the beginning of \Cref{app:entropy} prevail. For any \(t > 0\):
    \begin{enumerate}
        \item The differential entropy \(h(\vx_{t})\) exists and is \(> -\infty\).
        \item The differential entropy is increasing: \(\odv*{h(\vx_{t})}{t} > 0\).
    \end{enumerate}
\end{theorem}

To prove \Cref{thm:diffusion_entropy_increases}, we will break it up into several lemmas involving the transformation of \(p_{t}\) over time \(t\). 

\begin{lemma}\label{lem:diffusion_rv_density}
    The random variable \(\vx_{t}\) has a density given by 
    \begin{equation}
        p_{t}(\vxi) = \Ex\phi(\vxi \mid \vx, t^{2}\vI).
    \end{equation}
    In particular, \(p_{t}\) is smooth (infinitely differentiable) and positive everywhere.
\end{lemma}
\begin{proof}
    \phantom{}

    \textbf{Step 1: Establishing that \(\vx_{t}\) has a density.} The rough idea is that since we add Gaussian noise to obtain \(\vx_{t}\), we know that \(\vx_{t}\) is supported everywhere and thus is a continuous random variable with density. The formal proof of this part draws on some higher-level mathematics to sort out definitions, so feel free to skip it unless curious.

    To show that \(\vx_{t}\) has a density, we show that if \(A\) is a Borel-measurable set with Borel measure \(0\), then \(p_{t}(A) = 0\). Indeed, since \(\vx\) and \(\vg\) are independent,
    \begin{equation}
        \vx_{t} = \vx + t\vg \implies p_{t} = \phi(\cdot \mid \vzero, t^{2}\vI) * p
    \end{equation}
    where \(*\) denotes convolution (of probability densities/measures), it holds 
    \begin{align}
        p_{t}(A)
        &= \int_{\R^{D}}\indvar(\vxi \in A)p_{t}(\odif{\vxi}) \\
        &= \int_{\R^{D}}\indvar(\vxi \in A)(\phi(\cdot \mid \vzero, t^{2}\vI) * p)(\odif{\vxi}) \\ 
        &= \int_{\R^{D}}\int_{\R^{D}}\indvar(\vxi \in A)\phi(\odif{\vxi} - \vpsi \mid \vzero, t^{2}\vI)p(\odif{\vpsi}) \\
        &= \int_{\R^{D}}\int_{\R^{D}}\indvar(\vxi \in A)\phi(\odif{\vxi} \mid \vpsi, t^{2}\vI)p(\odif{\vpsi}) \\
        &= \int_{\R^{D}}\int_{\R^{D}}\indvar(\vxi \in A)\phi(\vxi \mid \vpsi, t^{2}\vI)\odif{\vxi}\ p(\odif{\vpsi}) \\
        &= \int_{\R^{D}}\underbrace{\bs{\int_{A}\phi(\vxi \mid \vpsi, t^{2}\vI)\odif{\vxi}}}_{= 0}p(\odif{\vpsi}) \\
        &= 0
    \end{align}
    where the function \(\phi(\odif{\vxi} - \vpsi)\) is the function \(\phi(\cdot - \vpsi)\) integrated over \(\vxi\), and  the underbraced equality is true because \(A\) has Borel measure \(0\) so integrating any function over \(A\) yields \(0\). So this proves that \(p_{t}\) has a density (which, remember, we will also call \(p_{t}\)).

    \textbf{Step 2: Finding the density of \(\vx_{t}\).}

    To show that \(\vx_{t}\) has the appropriate density,  we need to show that if \(A\) is any Borel-measurable set, then
    \begin{equation}
        p_{t}(A) = \int_{A}\Ex[\phi(\vxi \mid \vx, t^{2}\vI)]\odif{\vxi}.
    \end{equation}
    Indeed, we can obtain this by just expanding the convolution in a very similar direction:
    \begin{align}
        p_{t}(A)
        &= \int_{\R^{D}}\int_{A}\phi(\vxi \mid \vpsi, t^{2}\vI)\odif{\vxi}\ p(\odif{\vpsi}) \\
        &= \int_{A}\bs{\int_{\R^{D}}\phi(\vxi \mid \vpsi, t^{2}\vI)p(\odif{\vpsi})} \odif{\vxi} \\
        &= \int_{A}\Ex[\phi(\vxi \mid \vx, t^{2}\vI)]\odif{\vxi}
    \end{align}
    as desired. The only contentious equality here is the change in the order of integration, which is  justified by Tonelli's theorem and the fact that the integrand is the product of a normal density (measurable and positive everywhere) and an indicator function (measurable and non-negative everywhere) hence measurable and non-negative.

    We leave smoothness and positiveness as an exercise for the reader, so we are done.
\end{proof}

The above fact is somewhat remarkable at first sight: even for a completely irregular random variable \(\vx\) (say, a Bernoulli random variable, which does not have a density), its Gaussian smoothing admits a density for every (arbitrarily small) \(t > 0\).

\begin{lemma}
    For \(t > 0\), the differential entropy \(h(\vx_{t})\) exists and is \(> -\infty\).
\end{lemma}
\begin{proof}
    We use a classic yet tedious analysis argument. Since \(\vx_{t}\) has a density, we can write 
    \begin{equation}
        h(\vx_{t}) = -\int_{\R^{D}}p_{t}(\vxi)\log p_{t}(\vxi) \odif{\vxi}.
    \end{equation}
    Accordingly, let \(g \colon \R^{D} \to \R\) be defined as 
    \begin{equation}
        g(\vxi) := -p_{t}(\vxi)\log p_{t}(\vxi) \implies h(\vx_{t}) = \int_{\R^{D}}g(\vxi)\odif{\vxi}.
    \end{equation}
    As usual to bound the value of an integral in analysis, define 
    \begin{equation}
        g_{+}(\vxi) := \max(g(\vxi), 0), \quad g_{-}(\vxi) := \max(-g(\vxi), 0) \quad \implies \quad g = g_{+} - g_{-}\quad \text{and} \quad g_{+}, g_{-} \geq 0.
    \end{equation}
    Then 
    \begin{equation}
        h(\vx_{t}) = \int_{\R^{D}}g_{+}(\vxi)\odif{\vxi} - \int_{\R^{D}}g_{-}(\vxi)\odif{\vxi},
    \end{equation}
    and both integrals are guaranteed to be non-negative since their integrands are. In order to prove that \(h(\vx_{t})\) is well-defined (i.e., either real-valued, \(+\infty\), or \(-\infty\)), we need to show that \(\int_{\R^{D}}g_{+}(\vxi)\odif{\vxi} < \infty\) or \(\int_{\R^{D}}g_{-}(\vxi)\odif{\vxi} < \infty\). However, in order to show that \(h(\vx_{t}) > -\infty\), we just need to prove that \(\int_{\R^{D}}g_{-}(\vxi)\odif{\vxi} < \infty\). So we do the latter as it also proves the former.

    To bound the integral of \(g_{-}\) we need to understand the quantity \(g_{-}\). When is \(g\) negative?
    \begin{equation}
        g(\vxi) \leq 0 \iff p_{t}(\vxi)\log p_{t}(\vxi) \geq 0 \iff \log p_{t}(\vxi) \geq 0 \iff p_{t}(\vxi) \geq 1.
    \end{equation}
    Thus, it holds that 
    \begin{equation}
        g_{-}(\vxi) = \indvar(p_{t}(\vxi) \geq 1)\cdot (-g(\vxi)) = \indvar(p_{t}(\vxi) \geq 1)p_{t}(\vxi)\log p_{t}(\vxi).
    \end{equation}
    In order to bound the integral of \(g_{-}(\vxi)\), in this case we are lucky enough to be able to bound the function \(g_{-}(\vxi)\) itself. Namely, notice that 
    \begin{equation}
        \max_{\vxi \in \R^{D}}\phi(\vxi \mid \vmu, \vSigma) = \phi(\vmu \mid \vmu, \vSigma) = \frac{1}{\sqrt{(2\pi)^{D}\det(\vSigma)}}.
    \end{equation}
    In this case we only deal with \(\vSigma = t^{2}\vI\) which has determinant \(t^{2D}\), so
    \begin{equation}
        \phi(\cdot \mid \vmu, t^{2}\vI) \leq \frac{1}{(2\pi)^{D/2}t^{D}} := C_{t},
    \end{equation}
    which blows up as \(t \to 0\) but is finite for all finite \(t\). Therefore 
    \begin{equation}
        p_{t}(\vxi) = \Ex \phi(\vxi \mid \vx, t^{2}\vI) \leq \Ex C_{t} = C_{t}.
    \end{equation}
    Now there are two cases.
    \begin{itemize}
        \item If \(C_{t} < 1\), then \(p_{t}(\vxi) < 1\), so the indicator is never \(1\), hence \(g_{-} = 0\) identically and its integral is also \(0\).
        \item If \(C_{t} \geq 1\), then \(\log C_{t} \geq 0\), so since the logarithm is monotonically increasing,
        \begin{align}
            \int_{\R^{D}}g_{-}(\vxi)\odif{\vxi}
            &= \int_{\R^{D}}\indvar(p_{t}(\vxi) \geq 1)p_{t}(\vxi)\log p_{t}(\vxi)\odif{\vxi}  \\ 
            &= \Ex[\indvar(p_{t}(\vx_{t}) \geq 1)\log p_{t}(\vx_{t})]  \\ 
            &\leq \Ex[\indvar(p_{t}(\vx_{t}) \geq 1) \log C_{t}] \\ 
            &= \Pr[p_{t}(\vx_{t}) \geq 1]\log C_{t}.
        \end{align}
    \end{itemize}
    Hence we have \(\int_{\R^{D}}g_{-}(\vxi)\odif{\vxi} < \infty\), so the differential entropy \(h(\vx_{t})\) exists and is \(> -\infty\).
\end{proof}

Now to prove that the differential entropy is increasing over time, we will use a characterization of the time-evolution of the probability density \(p_{t}\). Such characterizations are called \textit{Fokker-Planck equations}. Namely, we will show that the Fokker-Planck equation of \(\vx_{t}\) (hence \(p_{t}\)) follows a reparameterized \textit{heat equation}. The heat equation is a famous PDE which describes the diffusion of heat through space. This intuitively should make sense, and paints a mental picture: as the time \(t\) increases, the probability from the original (perhaps tightly concentrated) \(\vx\) disperses across all of \(\R^{D}\) like heat radiating from a source in a vacuum. Experimentally this seems to happen, as in \Cref{fig:ve_forward_density}. But we need to prove this connection.

Central to the heat equation is a second-derivative term called the \textit{Laplacian} \(\Delta\), operating on a twice-differentiable function \(f \colon \R \times \R^{D} \to \R\) by 
\begin{equation}
    \Delta_{x} f_{t}(x) = \tr(\nabla_{x}^{2}f_{t}(x)) = \sum_{i = 1}^{d}\pdv[order=2]{f_{t}}{x_{i}}(x).
\end{equation}
Given this definition, the usual heat equation is the PDE 
\begin{equation}
    \pdv{f_{t}}{t}(x) = \Delta_{x} f_{t}(x).
\end{equation}
Theoretically, the heat equation describes \textit{time derivatives} of the densities \(p_{t}\) as functions of their instantaneous \textit{spatial derivatives} (in \(\vx\)), and it is an extremely useful, concise encapsulation of many regularity properties of the smoothed densities \(p_{t}\).\footnote{In fact, with a suitable (generalized) definition of the Laplacian operator, the heat equation actualy holds true in extreme generality---far beyond the case of additive Gaussian noise \cite{Bakry2016-pl}.}

By playing around with both sides we observe the following heat-like Fokker-Planck equation.
\begin{lemma}\label{lem:diffusion_rv_heat}
    The density \(p_{t}\) obeys the following heat-like PDE:
    \begin{equation}\label{eq:fokker_planck_ve}
        \pdv{p_{t}}{t}(\vxi) = t\Delta_{\vxi} p_{t}(\vxi).
    \end{equation}
\end{lemma}
\begin{proof}
    Everything here is smooth and integrable, and so we can exchange derivatives and expectations (integrals) freely. Hence 
    \begin{equation}
        \pdv{p_{t}}{t}(\vxi) = \pdv*{\Ex[\phi(\vxi \mid \vx, t^{2}\vI)]}{t} = \Ex\rs{\pdv*{\phi(\vxi \mid \vx, t^{2}\vI)}{t}}
    \end{equation}
    and 
    \begin{equation}
        \Delta_{\vxi} p_{t}(\vxi) = \Delta_{\vxi} \Ex[\phi(\vxi \mid \vx, t^{2}\vI)] = \Ex[\Delta_{\vxi}\phi(\vxi \mid \vx, t^{2}\vI)].
    \end{equation}
    It therefore suffices to show that
    \begin{equation}
        \pdv*{\phi(\vxi \mid \vx, t^{2}\vI)}{t} = t\cdot \Delta_{\vxi} \phi(\vxi \mid \vx, t^{2}\vI),
    \end{equation}
    because then taking expectations on both sides will yield the desired equation \eqref{eq:fokker_planck_ve}.

    We will calculate the left side and right side and show that they are equal. We have 
    \begin{equation}
        \pdv*{\phi(\vxi \mid \vx, t^{2}\vI)}{t} = \phi(\vxi \mid \vx, t^{2}\vI)\cdot \frac{1}{t^{3}}\cdot\bp{\norm{\vxi - \vx}_{2}^{2} - Dt^{2}}
    \end{equation}
    by a direct calculation. On the other hand, 
    \begin{align}
        \pdv*{\phi(\vxi \mid \vx, t^{2}\vI)}{\xi_{i}}
        &= -\phi(\vxi \mid \vx, t^{2}\vI)\cdot\frac{\xi_{i} - x_{i}}{t^{2}} \\ 
        \pdv*[order=2]{\phi(\vxi \mid \vx, t^{2}\vI)}{\xi_{i}}
        &= \phi(\vxi \mid \vx, t^{2}\vI)\cdot\frac{(\xi_{i} - x_{i})^{2} - t^{2}}{t^{4}} \\ 
        \Delta_{\vxi}\phi(\vxi \mid \vx, t^{2}\vI)
        &= \sum_{i = 1}^{D}\pdv*[order=2]{\phi(\vxi \mid \vx, t^{2}\vI)}{\xi_{i}} = \phi(\vxi \mid \vx, t^{2}\vI)\cdot\frac{1}{t^{4}}\cdot\bp{\norm{\vxi - \vx}_{2}^{2} - Dt^{2}}.
    \end{align}
    So we have 
    \begin{equation}
        \pdv*{\phi(\vxi \mid \vx, t^{2}\vI)}{t} = \phi(\vxi \mid \vx, t^{2}\vI)\cdot \frac{1}{t^{3}}\cdot\bp{\norm{\vxi - \vx}_{2}^{2} - Dt^{2}} = t\cdot \Delta_{\vxi}\phi(\vxi \mid \vx, t^{2}\vI).
    \end{equation}
    The heat-like equation is satisfied for \(\phi\) and hence \(p_{t}\), as desired.
\end{proof}

Now that we have this, we have a very simple proof for the second contention of \Cref{thm:diffusion_entropy_increases}.
\begin{lemma}\label{lem:diffusion_entropy_increases}
    For \(t > 0\), the differential entropy increases:
    \begin{equation}
        \odv*{h(\vx_{t})}{t} > 0.
    \end{equation}
\end{lemma}
\begin{proof}
     Because everything is smooth and integrable, we can swap the derivative with the integral and obtain
    \begin{align}
        \odv*{h(\vx_{t})}{t}
        &= -\odv*{\int_{\R^{D}}p_{t}(\vxi)\log p_{t}(\vxi)\odif{\vxi}}{t} \\
        &= -\int_{\R^{D}}\bs{\odv*{\bc{p_{t}(\vxi)\log p_{t}(\vxi)}}{t}}\odif{\vxi} \\
        &= -\int_{\R^{D}} \odv{p_{t}}{t}(\vxi)\bs{1 + \log p_{t}(\vxi)}\odif{\vxi} \\ 
        &= -t\int_{\R^{D}}\Delta_{\vxi}p_{t}(\vxi)\bs{1 + \log p_{t}(\vxi)}\odif{\vxi} \\
        &= t\int_{\R^{D}}\ip{\nabla_{\vxi} \log p_{t}(\vxi)}{\nabla_{\vxi}p_{t}(\vxi)}\odif{\vxi} \\
        &= t\int_{\R^{D}}\frac{\norm{\nabla_{\vxi}\log p_{t}(\vxi)}_{2}^{2}}{p_{t}(\vxi)}\odif{\vxi} \\ 
        &> 0.
    \end{align}
    Here the transfer from Laplacian to inner product is a result of Green's first identity, itself a consequence of integration by parts, and the identity \(\Delta f = \nabla \cdot (\nabla f)\) where \(\nabla \cdot\) is the divergence operator. Also, strict inequality holds in the last line because for it to not hold, \(\nabla_{\vxi}\log p_{t}(\vxi)\) would need to vanish almost everywhere (i.e., everywhere except possibly on a set of zero volume), but this would imply that \(\log p_{t}\) (and hence \(p_{t}\)) would be constants, which cannot be true since \(p_{t}\) is a density.
\end{proof}

This proves \Cref{thm:diffusion_entropy_increases}.


\subsection{Denoising Process Reduces Entropy Over Time}\label{sub:denoising_entropy_decreases}

Recall that in \Cref{sub:intro_diffusion_denoising} we start with the random variable \(\vx_{T}\) and iteratively denoise it using iterations of the form
\begin{equation}\label{eq:app_denoising_iteration}
    \hat{\vx}_{s} := \Ex[\vx_{s} \mid \vx_{t} = \hat{\vx}_{t}] = \frac{s}{t}\hat{\vx}_{t} + \bp{1 - \frac{s}{t}}\bar{\vx}^{\ast}(t, \hat{\vx}_{t}).
\end{equation}
for \(s, t \in \{t_{0}, t_{1}, \dots, t_{L}\}\) with \(s < t\) and \(\vx_{T} = \hat{\vx}_{T}\). We wish to prove that \(h(\hat{\vx}_{s}) < h(\hat{\vx}_{t})\), showing that the denoising process actually reduces the entropy.

Before we go about doing this, we make several remarks about the problem statement. First, Tweedie's formula \eqref{eq:tweedie} says that 
\begin{equation}
    \bar{\vx}^{\ast}(t, \vx_{t}) = \vx_{t} + t^{2}\nabla_{\vx_{t}} p_{t}(\vx_{t}),
\end{equation}
which likens a full denoising step from time \(t\) to time \(0\) to a gradient step on the log-density of \(\vx_{t}\). Can we get a similar result for the full denoising step from time \(t\) to time \(s\) in \eqref{eq:app_denoising_iteration}? It turns out that indeed we can, and it is pretty simple. By using \eqref{eq:app_denoising_iteration} and Tweedie's formula \eqref{eq:tweedie}, we obtain
\begin{equation}\label{eq:app_denoising_iteration_score}
    \Ex[\vx_{s} \mid \vx_{t}] = \frac{s}{t}\vx_{t} + \bp{1 - \frac{s}{t}}\bp{\vx_{t} + t^{2}\nabla_{\vx_{t}}\log p_{t}(\vx_{t})} = \vx_{t} + \bp{1 - \frac{s}{t}}t^{2}\nabla_{\vx_{t}}\log p_{t}(\vx_{t}).
\end{equation}
So this iterative denoising step is again a gradient step on the perturbed log-density \(\log p_{t}\) with a shrunken learning rate. In particular, this step can be seen as a perturbation of the distribution of the random variable \(\vx_{t}\) by the \textit{score function vector field}, suggesting a connection to stochastic differential equations (SDEs) and the theory of diffusion models \cite{song2020score}. Indeed, a proof of the following result \Cref{thm:conditioning_reduces_entropy} can be developed using this powerful machinery and a limiting argument (e.g., following the technical approach in the exposition of \cite{DBLP:conf/iclr/ChenC0LSZ23}). We will give a simpler proof here, which will use only elementary tools and  thereby illuminate some of the key quantities behind the process of entropy reduction via denoising. On the other hand, we will need to deal with some slightly technical calculations due to the fact that the denoising process in \Cref{thm:conditioning_reduces_entropy} does \textit{not} correspond exactly to the \textit{reverse} process associated to the noise addition process that generates the observation \(\vx_{t}\).\footnote{For those familiar with diffusion models, we refer here to the time-reversed forward process not coinciding with the sequence of iterates generated by the process defined by \Cref{thm:conditioning_reduces_entropy}. These processes coincide in a certain limit where infinitely many steps of \Cref{thm:conditioning_reduces_entropy} are taken with infinitely small levels of noise added at each step; for general, finite steps, we must introduce some approximations regardless of the level of sophistication of our tools.}

Let us define 
\begin{equation}
    \bar{\vx}^{\ast}(s, t, \vx_{t}) := \Ex[\vx_{s} \mid \vx_{t}],
\end{equation}
as the update step. We want to prove that \(h(\bar{\vx}^{\ast}(s, t, \vx_{t})) < h(\vx_{t})\), i.e., formally:
\begin{theorem}\label{thm:conditioning_reduces_entropy}
    Let the notation used at the beginning of \Cref{sec:entropy_diffusion} prevail. Suppose that \textit{either}:
    \begin{enumerate}
        \item \(0 < s < t \leq T\); or 
        \item \(0 = s < t \leq T\) and \(\vx\) does not have support contained in a subspace of codimension \(1\). 
    \end{enumerate}
    Also, suppose that \(U_{t} := \sup_{\vxi \in \R^{D}}\abs{\Delta \log p_{t}(\vxi)}\) satisfies \(U_{t} \leq \frac{2D}{(1 - \frac{s}{t})t^{2}}\). Then \(h(\bar{\vx}^{\ast}(s, t, \vx_{t})) < h(\vx_{t})\).
\end{theorem}
% \begin{remark}
%     In \Cref{thm:conditioning_reduces_entropy}, if \(s > 0\) then all conditions (1) --- (4) are met by default. So they are only really meaningful when \(s = 0\).
% \end{remark}

To prove this theorem we will need a set of results whose original form can be found in \cite{Gribonval2011-pf}.

\begin{lemma}[Generalization of \cite{Gribonval2011-pf}, Lemma A.1]\label{lem:gribonval_A1}
    Let the assumptions in \Cref{thm:conditioning_reduces_entropy} prevail. The Jacobian \(\pdv{\bar{\vx}^{\ast}(s, t)}{\vx_{t}}(\vx_{t})\) is symmetric positive definite.
\end{lemma}
\begin{proof}
    For this proof only, let \(\phi_{t}(\vx) := \phi(\vx \mid \vzero, t^{2}\vI)\). We have 
    \begin{equation}
        \pdv{\bar{\vx}^{\ast}(s, t)}{\vx_{t}}(\vx_{t}) = \vI + \bp{1 - \frac{s}{t}}t^{2}\nabla_{\vx_{t}}^{2}\log p_{t}(\vx_{t}).
    \end{equation}
    Here we expand 
    \begin{equation}
        \nabla_{\vx_{t}}^{2}\log p_{t}(\vx_{t}) = \frac{p_{t}(\vx_{t})\nabla_{\vx_{t}}^{2}p_{t}(\vx_{t}) - (\nabla_{\vx_{t}} p_{t}(\vx_{t}))(\nabla_{\vx_{t}} p_{t}(\vx_{t}))^{\top}}{p_{t}(\vx_{t})^{2}}.
    \end{equation}
    So we need to ensure that 
    \begin{align}
        &\vI + \bp{1 - \frac{s}{t}}t^{2}\frac{p_{t}(\vx_{t})\nabla_{\vx_{t}}^{2}p_{t}(\vx_{t}) - (\nabla_{\vx_{t}} p_{t}(\vx_{t}))(\nabla_{\vx_{t}} p_{t}(\vx_{t}))^{\top}}{p_{t}(\vx_{t})^{2}} \\
        =&\ \frac{p_{t}(\vx_{t})^{2}\vI + \bp{1 - \frac{s}{t}}t^{2}\bs{p_{t}(\vx_{t})\nabla_{\vx_{t}}^{2}p_{t}(\vx_{t}) - (\nabla_{\vx_{t}} p_{t}(\vx_{t}))(\nabla_{\vx_{t}} p_{t}(\vx_{t}))^{\top}}}{p_{t}(\vx_{t})^{2}}
    \end{align}
    is symmetric positive semidefinite. Since \(p_{t} > 0\), we only want to show that the numerator is symmetric positive semidefinite. Indeed it is obviously symmetric (by Clairaut's theorem). To show its positive semidefiniteness, note that
    \begin{equation}
        p_{t} = \phi_{t} * p \implies \nabla_{\vx_{t}}p_{t} = \nabla_{\vx_{t}}\phi_{t}* p \implies \nabla_{\vx_{t}}^{2}p_{t} = \nabla_{\vx_{t}}^{2}\phi_{t} * p.
    \end{equation}
    It holds that 
    \begin{align}
        \nabla_{\vx_{t}}\phi_{t}(\vx_{t})
        &= -\phi_{t}(\vx_{t}) \cdot\frac{\vx_{t}}{t^{2}}  \\ 
        \nabla_{\vx_{t}}^{2}\phi_{t}(\vx_{t})
        &= \phi_{t}(\vx_{t})\bs{\frac{\vx_{t}\vx_{t}^{\top}}{t^{4}} - \frac{\vI}{t^{2}}}.
    \end{align}
    Therefore, we can just use the convolution representation of \(p_{t}\), i.e.,
    \begin{equation}
        p_{t}(\vx_{t}) = \int_{\R^{D}}\phi_{t}(\vx_{t} - \vxi)p(\odif{\vxi}),
    \end{equation}
    (and similarly for \(\nabla_{\vx_{t}}p_{t}(\vx_{t})\) and \(\nabla_{\vx_{t}}^{2}p_{t}(\vx_{t})\)) and do a calculation for \(\vv \neq \vzero\):
    \begin{align}
        &\vv^{\top}\bs{\pdv{\bar{\vx}(s, t)}{\vx_{t}}(\vx_{t})}\vv \\ 
        &= p_{t}(\vx_{t})^{-2}\vv^{\top}\Bigg[p_{t}(\vx_{t})^{2}\vI + \bp{1 - \frac{s}{t}}t^{2}\int_{\R^{D}}\int_{\R^{D}}\phi_{t}(\vx_{t} - \vxi)\phi_{t}(\vx_{t} - \vpsi)\bs{\frac{\vpsi\vpsi^{\top}}{t^{4}} - \frac{\vI}{t^{2}}}p(\odif{\vxi})p(\odif{\vpsi}) \\ 
        &\qquad \qquad \qquad - \bp{1 - \frac{s}{t}}t^{2}\int_{\R^{D}}\int_{\R^{D}}\phi_{t}(\vx_{t} - \vxi)\phi_{t}(\vx_{t} - \vpsi)\bs{-\frac{\vxi}{t^{2}}}\bs{-\frac{\vpsi}{t^{2}}}^{\top}p(\odif{\vxi})p(\odif{\vpsi})\Bigg]\vv \\ 
        &= p_{t}(\vx_{t})^{-2}\vv^{\top}\Bigg[\bp{1 - \frac{s}{t}}t^{2}\int_{\R^{D}}\int_{\R^{D}}\phi_{t}(\vx_{t} - \vxi)\phi_{t}(\vx_{t} - \vpsi)\bs{\frac{\bp{1 - \frac{s}{t}}^{-1}\vI}{t^{2}}}p(\odif{\vxi})p(\odif{\vpsi}) \\
        &\qquad \qquad \qquad + \bp{1 - \frac{s}{t}}t^{2}\int_{\R^{D}}\int_{\R^{D}}\phi_{t}(\vx_{t} - \vxi)\phi_{t}(\vx_{t} - \vpsi)\bs{\frac{\vxi\vxi^{\top}}{2t^{4}} + \frac{\vpsi\vpsi^{\top}}{2t^{4}} - \frac{\vI}{t^{2}}}p(\odif{\vxi})p(\odif{\vpsi}) \\ 
        &\qquad \qquad \qquad - \bp{1 - \frac{s}{t}}t^{2}\int_{\R^{D}}\int_{\R^{D}}\phi_{t}(\vx_{t} - \vxi)\phi_{t}(\vx_{t} - \vpsi)\bs{\frac{\vxi\vpsi^{\top}}{t^{4}}}p(\odif{\vxi})p(\odif{\vpsi})\Bigg]\vv \\ 
        &= p_{t}(\vx_{t})^{-2}\bp{1 - \frac{s}{t}}t^{2}\int_{\R^{D}}\int_{\R^{D}}\phi_{t}(\vx_{t} - \vxi)\phi_{t}(\vx_{t} - \vpsi)\bs{\vv^{\top}\vA(\vxi, \vpsi)\vv}p(\odif{\vxi})p(\odif{\vxi})
    \end{align}
    where 
    \begin{align}
        &\vA(\vxi, \vpsi) = \frac{1}{t^{2}}\bp{\bp{1 - \frac{s}{t}}^{-1} - 1}\vI + \frac{1}{2t^{4}}(\vxi - \vpsi)(\vxi - \vpsi)^{\top} \\ 
        \implies 
        &\vv^{\top}\vA(\vxi, \vpsi)\vv = \frac{1}{t^{2}}\bp{\bp{1 - \frac{s}{t}}^{-1} - 1}\norm{\vv}_{2}^{2} + \frac{1}{2t^{4}}[(\vxi - \vpsi)^{\top}\vv]^{2}.
    \end{align}
    This term is zero precisely when \(s = 0\) \textit{and} \(\vxi - \vpsi\) is orthogonal to \(\vv\). Then, the whole integral (i.e., the original quadratic form) is \(0\) only when \(s = 0\) and \(\vx\) is supported on a subspace which is orthogonal to \(\vv\). But this is ruled out by assumption, so the Jacobian \(\pdv{\bar{\vx}^{\ast}(s, t)}{\vx_{t}}(\vx_{t})\) is symmetric positive definite.
\end{proof}

\begin{corollary}[Generalization of \cite{Gribonval2011-pf} Corollary A.2]\label{cor:gribonval_A2}
    Let \(f \colon \R^{D} \to \R^{D}\) be any smooth (i.e., infinitely differentiable) function whose Jacobian \(\pdv{f}{\vx}(\vx)\) is symmetric positive definite. Then \(f\) is injective, and hence invertible as a function \(\R^{D} \to \Range(f)\) where \(\Range(f)\) is the range of \(f\).
\end{corollary}
\begin{proof}
    Suppose that \(f\) were not injective, i.e., there exists \(\vx, \vx^{\prime}\) such that \(f(\vx) = f(\vx^{\prime})\) while \(\vx \neq \vx^{\prime}\). Define \(\vv := (\vx^{\prime} - \vx)/\norm{\vx^{\prime} - \vx}_{2}\). Define the function \(g \colon \R \to \R\) as \(g(t) := \vv^{\top}f(\vx + t\vv)\). Then \(g(0) = \vv^{\top}f(\vx) = \vv^{\top}f(\vx^{\prime}) = g(\norm{\vx^{\prime} - \vx}_{2})\). Since \(f\) is smooth, \(g\) is smooth, so the derivative  \(g^{\prime}\) must vanish for some \(t^{\ast} \in (0, \norm{\vx^{\prime} - \vx}_{2})\). However,
    \begin{equation}
        g^{\prime}(t^{\ast}) := \vv^{\top}\bs{\pdv{f}{\vx}(\vx + t^{\ast}\vv)}\vv > 0
    \end{equation}
    since the Jacobian is positive definite. Thus we arrive at a contradiction, as claimed.
\end{proof}

We are now ready to prove \Cref{thm:conditioning_reduces_entropy}.

\begin{proof}[Proof of \Cref{thm:conditioning_reduces_entropy}]
    % For any \(s > 0\), by \Cref{lem:diffusion_rv_density} (and \Cref{lem:diffusion_rv_heat}), it is easy to show that \(p_{s}\) admits properties 2(a), 2(b), 2(c), 2(d) in the statement of \Cref{thm:conditioning_reduces_entropy}. So we shall just work with general \(s\), \(0 \leq s < t\), and assume that \(p_{s}\) has the properties 2(a), 2(b), 2(c), 2(d).

    The key to our approach will be to exploit the fact that the denoising process applies a deterministic map to the random variable \(\vx_{t}\), namely the update map \(\bar{\vx}^{\ast}(s, t, \cdot)\), and use this to characterize the density \(\hat{p}_{s}\) which is the density of \(\bar{\vx}^{\ast}(s, t, \vx_{t})\).

    Namely, we can combine the above two results \Cref{lem:gribonval_A1} and \Cref{cor:gribonval_A2} to help us obtain this density. Since \(p_{t}\) (hence  \(\log p_{t}\)) is smooth (cf \Cref{lem:diffusion_rv_density}), \(\bar{\vx}^{\ast}(s, t, \cdot)\) is a smooth function from \(\R^{D}\) to \(\R^{D}\). Applying \Cref{lem:gribonval_A1}, we obtain that its Jacobian \(\pdv{\bar{\vx}^{\ast}(s, t)}{\vx_{t}}\) is positive semidefinite. Then applying \Cref{cor:gribonval_A2}, we obtain that it is injective and thus invertible on its range. We denote its inverse as \(\bar{\vx}^{\ast}(s, t)^{-1}\). Using a change-of-variables formula, the density \(\hat{p}_{s, t}\) of \(\bar{\vx}^{\ast}(s, t, \vx_{t})\) is given by 
    \begin{equation}
        \hat{p}_{s, t}(\hat{\vx}_{s}) := \frac{(p_{t} \circ \bar{\vx}^{\ast}(s, t)^{-1})(\hat{\vx}_{s})}{\det(\pdv{\bar{\vx}^{\ast}(s, t)}{\vx_{t}}(\bar{\vx}^{\ast}(s, t)^{-1}(\hat{\vx}_{s})))}.
    \end{equation}
    Then, with \(S\) the range of \(\bar{\vx}^{\ast}(s, t)\), it follows that 
    \begin{align}
        &h(\bar{\vx}^{\ast}(s, t, \vx_{t})) \\
        &= -\int_{S}\frac{(p_{t} \circ \bar{\vx}^{\ast}(s, t)^{-1})(\vxi)}{\det(\pdv{\bar{\vx}^{\ast}(s, t)}{\vx_{t}}(\bar{\vx}^{\ast}(s, t)^{-1}(\vxi)))} \log \frac{(p_{t} \circ \bar{\vx}^{\ast}(s, t)^{-1})(\vxi)}{\det(\pdv{\bar{\vx}^{\ast}(s, t)}{\vx_{t}}(\bar{\vx}^{\ast}(s, t)^{-1}(\vxi)))} \odif{\vxi} \\ 
        &= -\int_{S}\frac{(p_{t} \circ \bar{\vx}^{\ast}(s, t)^{-1})(\vxi)}{\det(\pdv{\bar{\vx}^{\ast}(s, t)}{\vx_{t}}(\bar{\vx}^{\ast}(s, t)^{-1}(\vxi)))} \log((p_{t} \circ \bar{\vx}^{\ast}(s, t)^{-1})(\vxi))\odif{\vxi} \\ 
        &\qquad + \int_{S}\frac{(p_{t} \circ \bar{\vx}^{\ast}(s, t)^{-1})(\vxi)}{\det(\pdv{\bar{\vx}^{\ast}(s, t)}{\vx_{t}}(\bar{\vx}^{\ast}(s, t)^{-1}(\vxi)))}\logdet\rp{\pdv{\bar{\vx}^{\ast}(s, t)}{\vx_{t}}(\bar{\vx}^{\ast}(s, t)^{-1}(\vxi))}\odif{\vxi} \\ 
        &= -\int_{\R^{D}}p_{t}(\vxi)\log p_{t}(\vxi)\odif{\vxi} + \int_{S}\frac{(p_{t} \circ \bar{\vx}^{\ast}(s, t)^{-1})(\vxi)}{\det(\pdv{\bar{\vx}^{\ast}(s, t)}{\vx_{t}}(\bar{\vx}^{\ast}(s, t)^{-1}(\vxi)))}\logdet\rp{\pdv{\bar{\vx}^{\ast}(s, t)}{\vx_{t}}(\bar{\vx}^{\ast}(s, t)^{-1}(\vxi))}\odif{\vxi} \\ 
        &= h(\vx_{t}) - \int_{S}\frac{(p_{t} \circ \bar{\vx}^{\ast}(s, t)^{-1})(\vxi)}{\det(\pdv{\bar{\vx}^{\ast}(s, t)}{\vx_{t}}(\bar{\vx}^{\ast}(s, t)^{-1}(\vxi)))}\log\rp{\frac{1}{\det(\pdv{\bar{\vx}^{\ast}(s, t)}{\vx_{t}}(\bar{\vx}^{\ast}(s, t)^{-1}(\vxi)))}}\odif{\vxi}.
    \end{align}
    We will study the last term (including the \(-\)), and show that it is negative.

    By concavity, one has \(-x\log x \leq 1 - x\) for every \(x \geq 0\). Hence 
    \begin{align}
        h(\bar{\vx}^{\ast}(s, t, \vx_{t})) - h(\vx_{t})
        &= - \int_{S}\frac{(p_{t} \circ \bar{\vx}^{\ast}(s, t)^{-1})(\vxi)}{\det(\pdv{\bar{\vx}^{\ast}(s, t)}{\vx_{t}}(\bar{\vx}^{\ast}(s, t)^{-1}(\vxi)))}\log\rp{\frac{1}{\det(\pdv{\bar{\vx}^{\ast}(s, t)}{\vx_{t}}(\bar{\vx}^{\ast}(s, t)^{-1}(\vxi)))}}\odif{\vxi} \\ 
        &\leq  \int_{S}(p_{t} \circ \bar{\vx}^{\ast}(s, t)^{-1})(\vxi)\cdot \bp{1 - \frac{1}{\det(\pdv{\bar{\vx}^{\ast}(s, t)}{\vx_{t}}(\bar{\vx}^{\ast}(s, t)^{-1}(\vxi)))}}\odif{\vxi} \\ 
        &= \int_{S}(p_{t} \circ \bar{\vx}^{\ast}(s, t)^{-1})(\vxi)\odif{\vxi} - \int_{S}\frac{(p_{t} \circ \bar{\vx}^{\ast}(s, t)^{-1})(\vxi)}{\det(\pdv{\bar{\vx}^{\ast}(s, t)}{\vx_{t}}(\bar{\vx}^{\ast}(s, t)^{-1}(\vxi)))}\odif{\vxi} \\
        &= \int_{\R^{D}}p_{t}(\vxi)\det\rp{\pdv{\bar{\vx}^{\ast}(s, t)}{\vx_{t}}(\bar{\vx}^{\ast}(s, t)^{-1}(\vxi))}\odif{\vxi} - \int_{S}\hat{p}_{s, t}(\vx_{t})\odif{\vxi} \\
        &= \int_{\R^{D}}p_{t}(\vxi)\det\rp{\vI + \bp{1 - \frac{s}{t}}t^{2}\nabla_{\vx_{t}}^{2}\log p_{t}(\vxi)}\odif{\vxi} - 1.
    \end{align}
    Now, by the AM-GM inequality on eigenvalues, we have for any symmetric positive definite matrix \(\vM\) the bound 
    \begin{equation}
        \det(\vM)^{1/D} = \prod_{i = 1}^{D}\lambda_{i}(\vM)^{1/D} \leq \frac{\sum_{i = 1}^{D}\lambda_{i}(\vM)}{D} = \frac{\tr(\vM)}{D},
    \end{equation}
    which we can apply to the above expression and obtain 
    \begin{align}
        &\int_{\R^{D}}p_{t}(\vxi)\det\rp{\vI + \bp{1 - \frac{s}{t}}t^{2}\nabla_{\vx_{t}}^{2}\log p_{t}(\vxi)}\odif{\vxi} \\
        &\leq \int_{\R^{D}} p_{t}(\vxi) \tr\rp{\frac{1}{D}\bs{\vI + \bp{1 - \frac{s}{t}}t^{2}\nabla_{\vx_{t}}^{2}\log p_{t}(\vxi)}}^{D}\odif{\vxi} \\
        &= \int_{\R^{D}} p_{t}(\vxi)\bp{1 + \frac{\bp{1 - \frac{s}{t}}t^{2}}{D}\tr(\nabla_{\vx_{t}}^{2}\log p_{t}(\vxi))}^{D}\odif{\vxi} \\
        &= \int_{\R^{D}} p_{t}(\vxi)\bp{1 + \frac{\bp{1 - \frac{s}{t}}t^{2}}{D}\Delta \log p_{t}(\vxi)}^{D}\odif{\vxi}.
    \end{align}
    Recalling that we define \(U_{t} := \sup_{\vxi \in \R^{D}}\abs{\Delta_{\vxi} \log p_{t}(\vxi)} < \infty\). Then it holds
    \begin{equation}
        -\frac{\bp{1 - \frac{s}{t}}t^{2}}{D}U_{t} \leq \frac{\bp{1 - \frac{s}{t}}t^{2}}{D}\Delta_{\vxi} \log p_{t}(\vxi) \leq \frac{\bp{1 - \frac{s}{t}}t^{2}}{D}U_{t}.
    \end{equation}
    Meanwhile, the function \(x \mapsto (1 + x)^{D}\) is convex on \([-1, \infty)\), so for \(-(1-s/t)t^{2}U_{t}/D \leq x \leq (1-s/t)t^{2}U_{t}/D\) we have 
    \begin{align}
        (1 + x)^{d} 
        &\leq \bp{1 - \frac{\bp{1 - \frac{s}{t}}t^{2}U}{D}}^{D} + \underbrace{\bs{\bp{1 + \frac{\bp{1 - \frac{s}{t}}t^{2}U}{D}}^{D} - \bp{1 - \frac{\bp{1 - \frac{s}{t}}t^{2}U}{D}}^{D}}}_{M(s, t, D, U)}x \\ 
        &\leq 1 + M(s, t, D, U)x.
    \end{align}
    Here \(M(s, t, D, U) > 0\) (since \(U > 0\) as \(p_{t}\) is a density and cannot be constant). Applying this bound, we obtain
    \begin{align}
        &\int_{\R^{D}} p_{t}(\vxi)\bp{1 + \frac{\bp{1 - \frac{s}{t}}t^{2}}{D}\Delta \log p_{t}(\vxi)}^{D}\odif{\vxi} \\ 
        &\leq \int_{\R^{D}}p_{t}(\vxi)\bp{1 + M(s, t, D, U)\Delta \log p_{t}(\vxi)}\odif{\vxi} \\
        &= 1 + M(s, t, D, U)\int_{\R^{D}}p_{t}(\vxi)\Delta \log p_{t}(\vxi)\odif{\vxi} \\
        &= 1 - M(s, t, D, U)\int_{\R^{D}}\ip{\nabla_{\vxi} p_{t}(\vxi)}{\nabla_{\vxi}\log p_{t}(\vxi)}\odif{\vxi} \\
        &= 1 - M(s, t, D, U)\int_{\R^{D}}p_{t}(\vxi)\norm{\nabla \log p_{t}(\vxi)}_{2}^{2}\odif{\vxi},
    \end{align}
    where the last few lines are the same as in the proof of \Cref{lem:diffusion_entropy_increases}. Combining this result with our previous estimate,
    \begin{equation}
        h(\bar{\vx}^{\ast}(s, t, \vx_{t})) - h(\vx_{t}) \leq - M(s, t, D, U)\int_{\R^{D}}p_{t}(\vxi)\norm{\nabla \log p_{t}(\vxi)}_{2}^{2}\odif{\vxi} < 0
    \end{equation}
    where the inequality is strict by the same argument as in \Cref{lem:diffusion_entropy_increases}.
\end{proof}

\begin{lemma}\label{lem:perturbed_density_uniform_control_laplacian}
    Let the assumptions in \Cref{thm:conditioning_reduces_entropy} prevail. Then 
    \begin{equation}
        \sup_{\vxi \in \R^{D}}\abs{\Delta_{\vxi}\log p_{t}(\vxi)} < \infty.
    \end{equation}
\end{lemma}

\begin{proof}
    Let us follow the proof of \Cref{lem:diffusion_rv_heat} to obtain
    \begin{align}
        \abs{\Delta_{\vxi}\log p_{t}(\vxi)}
        &= \abs*{\Ex\rs{\phi(\vxi \mid \vx, t^{2}\vI) \cdot \frac{1}{t^{4}} \cdot (\norm{\vxi - \vx}_{2}^{2} - Dt^{2})}} \\ 
        &\leq \frac{1}{t^{4}}\Ex[\phi(\vxi \mid \vx, t^{2}\vI)\norm{\vxi - \vx}_{2}^{2}] + \frac{D}{t^{2}}\Ex[\phi(\vxi \mid \vx, t^{2}\vI)].
    \end{align}
    In the proof of \Cref{lem:diffusion_rv_density}, we already showed that \(\phi(\cdot \mid \vx, t^{2}\vI) \leq C_{t}\) for some constant \(C_{t}\) (depending on \(D\) too, but not on \(\vx\)), so it holds 
    \begin{equation}
        \abs{\Delta_{\vxi} \log p_{t}(\vxi)} \leq \frac{1}{t^{4}}\Ex[\phi(\vxi \mid \vx, t^{2}\vI)\norm{\vxi - \vx}_{2}^{2}] + \frac{C_{t}D}{t^{2}}.
    \end{equation}
    To control the first term, we need to find an upper bound for the expression 
    \begin{equation}
        \sup_{\vxi \in \R^{D}}\phi(\vxi \mid \vx, t^{2}\vI)\norm{\vxi - \vx}_{2}^{2}.
    \end{equation}
    For this, notice that \(\phi(\vxi \mid \vx, t^{2}\vI)\) is also a function of \(\norm{\vxi - \vx}_{2}\). So we can write this whole thing as 
    \begin{equation}
        \sup_{x \in \R}\frac{1}{(2\pi)^{D/2}t^{D}}e^{-x^{2}/(2t^{2})}x^{2} = \frac{1}{(2\pi)^{D/2}t^{D}}\sup_{x  \in \R}e^{-x^{2}/(2t^{2})}x^{2}.
    \end{equation}
    Of course the tails of \(e^{-x^{2}/(2t^{2})}\) decay much faster than \(x^{2}\) grows, so \(\lim_{\abs{x} \to \infty}e^{-x^{2}/(2t^{2})}x^{2} = 0\). Thus to find the supremum we can enumerate the critical points and compare their values. The derivative of this expression is 
    \begin{equation}
        \odv*{[e^{-x^{2}/(2t^{2})}x^{2}]}{x} = \frac{e^{-x^{2}/(2t^{2})}}{t^{2}}\cdot x\cdot (2t^{2} - x^{2}),
    \end{equation}
    so the critical points are 
    \begin{equation}
        x = 0; \qquad x = +\sqrt{2}t; \qquad x = -\sqrt{2}t.
    \end{equation}
    The former critical point has an objective value of \(0\) while the latter two have objective values of \(2t^{2}/e\), clearly larger. So actually we have 
    \begin{equation}
        \sup_{\vxi \in \R^{D}}\phi(\vxi \mid \vx, t^{2}\vI)\norm{\vxi - \vx}_{2}^{2} \leq \frac{2}{(2\pi)^{D/2}t^{D-2}e} := C_{t}^{\prime}.
    \end{equation}
    Thus it follows that 
    \begin{equation}
        \abs{\Delta_{\vxi}\log p_{t}(\vxi)} \leq \frac{C_{t}^{\prime}}{t^{4}} + \frac{C_{t}D}{t^{2}},
    \end{equation}
    which is uniformly bounded in \(\vxi\), as desired.   
\end{proof}
