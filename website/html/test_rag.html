RAG Model Integration Test

This page demonstrates the new RAG model functionality. Click the chat button in the top-right to test the model switching feature.

Features Added:

  • ✅ requestRAG function - Communicates with the RAG proxy at deep-representation-learning-book-proxy.tianzhechu2.workers.dev
  • ✅ Model switch button - Toggle between Original (🤖) and RAG (🧠) models
  • ✅ Visual indicators - Blue for Original model, Green for RAG model
  • ✅ Position - Model switch button is positioned to the left of the Send button
  • ✅ State management - Preserves model selection during chat session

How to Use:

  1. Click the chat button (💬) in the top-right corner
  2. The model switch button will appear to the left of the Send button
  3. 🤖 (Blue) = Original model
  4. 🧠 (Green) = RAG model
  5. Click the model switch button to toggle between models
  6. Send your questions and observe the different responses

Technical Details:

  • Original Model: Uses OpenAI-style API format with /api/chat endpoint
  • RAG Model: Uses {query, mode} format with /query endpoint
  • Proxy URL: https://deep-representation-learning-book-proxy.tianzhechu2.workers.dev
  • Default Mode: "hybrid" for RAG queries
